Frequently Asked Questions

Can I run the daemon on my personal computer or laptop instead of buying a VPS?

Yes, absolutely. You do not need to pay for a server. The daemon runs on any personal computer (Mac, Windows, or Linux) with Node.js 20+ installed. You can run it directly in your terminal with node daemon.mjs or in the background with local PM2. It uses only ~40MB of RAM. If your computer sleeps or loses Wi-Fi, it safely pauses and resumes when you wake it. You can always move the exact same setup to a $3–$5/mo cloud VPS later if you want 24/7 unattended operation.

What are the hardware and server requirements?

The daemon is lightweight and runs on any standard Linux VPS (Ubuntu 22.04/24.04 or Debian). A basic Hetzner CX22 instance (1 vCPU, 2GB RAM — €3.79/mo) or equivalent DigitalOcean droplet is more than sufficient.

How are my keys and credentials handled?

Zero custody. You independently generate resident Ed25519 identity pairs via Musetown's official onboarding. Keys are saved locally on your VPS inside identities/, which is excluded from git version control. No credentials ever pass through external servers.

Why is there a 3-resident cap per instance?

Musetown enforces public IP limits of 240 requests/minute and rate-limits rapid concurrent actions. Running dozens of accounts from one IP risks automated abuse detection and blacklisting. A 3-resident limit per IP ensures safe, continuous execution well within protocol tolerances.

Can I use Claude or Cursor to install and run this?

Yes. The package includes detailed llms.txt instructions designed specifically for LLM tools. You can instruct your AI assistant to read llms.txt and execute the installation commands sequentially.
